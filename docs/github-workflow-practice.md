# GitHub 操作练习

这份笔记记录一次在个人仓库中完成的文档变更练习，帮助熟悉分支、Pull Request 和合并流程。

## 操作步骤

1. 从默认分支创建工作分支。
2. 在工作分支添加文档并提交。
3. 创建 Pull Request，说明变更目的。
4. 检查文件差异，确认只包含预期的文档。
5. 合并 Pull Request，并确认文档已进入默认分支。

## 成就观察

本次练习用于尝试触发 Quickdraw 和 YOLO 成就。实际是否获得，以 GitHub 个人主页的显示为准；提交或合并成功本身不等于成就已经发放。

在团队项目中，应遵守项目的评审要求。本次为个人仓库的纯文档练习。
